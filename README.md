# AI Provider Google Gemini

Use Google Gemini in Backdrop to draft text, analyze images, generate images, or create embeddings for semantic search. Pick a model that supports the operation your feature needs.

## Installation

Install and enable this module with AI and Key. [Backdrop module installation guide](https://backdropcms.org/user-guide/modules)

Store your service credentials using the Key module. Choose the provider in **Configuration → AI → Settings → Providers**. [Setup and troubleshooting](https://github.com/backdrop-contrib/ai_provider_google_gemini/wiki)
